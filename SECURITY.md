# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

OpenPhysicalAI Lab takes security and isolation seriously, particularly regarding sidecar process management, RPC boundaries, and local LLM API interactions.

If you discover a security vulnerability:
1. **Do NOT open a public GitHub issue.**
2. Send a report via [GitHub Security Advisories](https://github.com/VedantJadhav701/OpenphysicalAI-lab/security/advisories/new) or email the project author directly at `vedantjadhav701@gmail.com` with:
   - A description of the issue.
   - Steps or proof-of-concept to reproduce it.
   - Potential impact.
3. We will acknowledge receipt within 48 hours and work with you to release a fix before public disclosure.
